# 🎬 Movie Recommendation System

A content-based movie recommendation web application built with Python, Pandas, and Streamlit, featuring real-time poster fetching via the OMDb API.

## 🚀 Live Demo
Check out the live app here: [Wanna Watch More Movies](https://wannawatchmoremovies.streamlit.app/)

## 🛠️ Built With
* **Python** (Core logic and data processing)
* **Streamlit** (Interactive web app framework)
* **Pandas & NumPy** (Data manipulation and matrix calculation)
* **Scikit-Learn** (Cosine similarity model)
* **OMDb API** (Dynamic movie poster fetching)

## 📌 Features
* Select any movie from a comprehensive dropdown list.
* Instantly retrieves top 5 similar movie recommendations.
* Displays high-quality movie posters alongside titles in a responsive 2x5 grid layout.
